# TimeParadox

TimeParadox is a personal time planning and productivity tracking application.

The goal is to plan weekly time, track actual work sessions, and analyze the difference between planned and actual time.

## Core Features

- Weekly time planning
- Task management
- Focus timer
- Automatic time tracking
- Weekly productivity dashboard
- Planned vs actual analysis
- Productivity analytics
- AI-powered productivity assistant

## Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy

### Frontend
- React
- TypeScript

### Database
- SQLite
- PostgreSQL (planned)
